depends on it (brief §6.4).

**Status values:**

- **confirmed**: matches the brief.
- **contradicts brief**: the brief is wrong; the plan adjusts.
- **reported**: found by research but not yet reproduced by us. Re-check against the pinned version when code first depends on it.
- **pending**: not yet checked.
