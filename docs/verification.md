# Verification log

Every ⚠ fact from `docs/BRIEF.md` or `PLAN.md` gets an entry here before code
depends on it (brief §6.4).

**Status values:**

- **confirmed**: matches the brief.
- **contradicts brief**: the brief is wrong; the plan adjusts.
- **reported**: found by research but not yet reproduced by us. Re-check against the pinned version when code first depends on it.
- **pending**: not yet checked.

Seeded 2026-09-30 from planning research. Web research was done by subagents, from primary sources where possible; the tagma rows come from reading the source directly.
